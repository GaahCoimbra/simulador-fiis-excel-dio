# simulador-fiis-excel-dio
Simulador de Investimentos em Fundos Imobiliários (FIIs) desenvolvido em Excel com foco em Visualização Mobile. Permite simulação de aportes, projeção de património/dividendos e alocação dinâmica de carteira baseada no perfil do investidor via PROCV e chave composta. Projeto do curso DIO Santander - Excel com IA e Claude com o Expert Felipe Aguiar.
